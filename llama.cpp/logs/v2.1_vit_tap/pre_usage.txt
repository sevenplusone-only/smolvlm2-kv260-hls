=== NOTE: zero UUID is expected pre-run ===
On KV260 edge, xclbin is loaded lazily by user process (ggml_xrt::get_runtime
via xrt::device::load_xclbin(path) reading GGML_XRT_XCLBIN). xmutil loadapp
only installs the bitstream via fpga_manager. xbutil dynamic-regions reports
zero UUID until the first llama-server XRT init.
Post-run check: xbutil examine dynamic-regions should show non-zero UUID + CU
usage > 0 if Tap D was triggered.
